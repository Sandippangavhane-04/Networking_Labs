RIP Routing Lab – Cisco Packet Tracer

📌 Overview

This lab demonstrates the configuration and verification of Routing Information Protocol (RIP) using Cisco Packet Tracer.

🎯 Objectives

- Configure RIP between multiple routers
- Configure router interfaces and IP addressing
- Advertise connected networks using RIP
- Understand dynamic routing using RIP
- Verify RIP routes and routing information
- Practice basic routing troubleshooting

🛠️ Tools Used

- Cisco Packet Tracer
- Cisco IOS CLI
- RIP Version 2

⚙️ Configuration

RIP Version 2 was configured using the following commands:

router rip
version 2
network <network-address>
no auto-summary

🔍 Verification Commands

show ip protocols
show ip route
show ip route rip

📚 Key Concepts Practiced

- Dynamic Routing
- RIP Version 2
- Network Advertisement
- Hop Count
- Routing Table
- Route Verification
- Basic Troubleshooting

✅ Result

Successfully configured and verified RIP Version 2 routing between routers in Cisco Packet Tracer.
